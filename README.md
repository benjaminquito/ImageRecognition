# ImageRecognition
These are processes used to build the Supervised Learning Model: 

1.  ML algorithm – CNN
2.  Training – loading the training data and the expected output of the data and coming up with the expected results. The training percentage is 80%, or an 80/20 split ratio; this follows the Pareto principles of 80% effects and 20% causation which is used by Zhao et al. (2018)  
3.  Testing – loading testing data differently from the training data and predicting the correct results. The testing percentage is 20%
4.  Evaluation – loading new data and calculating the data. The evaluation process loads new data, which is different from the training and testing data. The purpose of this is to make sure that the model will predict output from the data that it has never encountered before; this will improve the accuracy of the model.
